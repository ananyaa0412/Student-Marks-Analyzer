# 📊 Students Marks Analyzer

## 📌 Project Description

Students Marks Analyzer is a Python-based project designed to analyze student marks and generate useful insights such as total marks, average score, highest marks, lowest marks, and grades. This project helps in understanding student performance efficiently.

---

## 🚀 Features

- Add and store student marks
- Calculate total and average marks
- Find highest and lowest scores
- Generate grades automatically
- Display student performance analysis
- Simple and easy-to-use Python program

---

## 🛠️ Technologies Used

- Python 3
- CSV/File Handling (Optional)
- Pandas Library (Optional)
